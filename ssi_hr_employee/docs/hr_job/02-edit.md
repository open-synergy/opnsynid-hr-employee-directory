# Edit Job Position

> **Module:** `ssi_hr_employee`\
> **Extends:** ssi_hr — model `hr.job`, aksi `02-edit`

## Additional Fields

- Anchor: after Flow step 3 (**Edit** button) of the base instruction, the fields below
  can be changed in step 4.
  - On the **Recruitment** tab, **Job Family Level**: Change the level. **Job Grades**
    is reset to empty, so select the job grades again.
  - On the **Recruitment** tab, **Job Grades**: Change the grades of the position. Only
    the job grades of the selected **Job Family Level** can be chosen.
  - **Job Description** tab: Change the job descriptions of the position.
